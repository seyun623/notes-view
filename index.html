조건은 이 브라우저에 저장됩니다.

직무는 여러 개 선택할 수 있습니다. 선택한 직무 중 하나에 해당하는 공고를 표시합니다.

경력 미확인 공고도 포함됩니다. 지원 조건은 원문에서 확인하세요.

추가 필터

지역 키워드는 하나 이상 일치하면 포함합니다. 지역 미기재 공고는 지역 조건 적용 시 제외됩니다.

적합도는 관심 직무와의 일치 정도를 나타내는 참고값이며, 합격 가능성이 아닙니다.

백업·복원

저장한 공고·지원 상태·채널 확인 기록·직접 추가한 공고는 이 브라우저에만 저장됩니다. 백업 파일에는 공고 식별자와 지원 상태, 채널 확인 시각, 직접 추가한 공고 내용이 포함됩니다. 복원은 기존 기록에 추가하며, 같은 채널·공고는 더 최근 기록을 남깁니다.

마감된 공고도 저장 목록에서 확인할 수 있습니다.

공고 직접 추가

직접 확인하다 찾은 공고를 적어 두면 목록에 ‘직접 추가’ 표시로 함께 보입니다. 이 브라우저에만 저장되고 백업 파일에 포함됩니다.

    직접 확인할 채널

    자동 수집이 안 되는 곳입니다. 바로가기로 살펴본 뒤 ‘확인함’을 누르면 다음 권장일을 알려 드립니다. 확인 기록은 이 브라우저에만 저장됩니다.

        원문 검증 범위

        검색·필터 적용 전, 중복을 묶은 현재 목록 기준입니다. 점검 시도는 모집 중 확인과 다릅니다.

        등록된 기업 채용관

        등록 정보와 실제 수집 성공은 별개입니다. 그룹 태그는 탐색용 분류이며 현재 지배관계를 보증하지 않습니다.

        사이트별 수집 현황

        지금 자동 수집이 멈춘 곳

        각 사이트의 마지막 실행 기록입니다. 0건은 공고가 없다는 뜻으로 단정할 수 없습니다.
